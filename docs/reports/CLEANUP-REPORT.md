## Task 2: SQLite Boilerplate Deduplication

**Work Done:**

### New Package: `internal/dbutil`
Extracted shared SQLite initialization logic into a single reusable function:

```go
// OpenSQLite(path string) (*sql.DB, error)
```

**Functionality:**
1. Creates parent directories if missing (via `os.MkdirAll`)
2. Opens SQLite connection with busy-timeout pragma
3. Sets `MaxOpenConns(1)` for single-writer serialization
4. Applies three durability pragmas atomically:
   - `PRAGMA journal_mode=WAL;` (crash-safe)
   - `PRAGMA synchronous=FULL;` (durable on disk before return)
   - `PRAGMA foreign_keys=ON;` (referential integrity)
5. Returns ready-to-use `*sql.DB`, or closes and returns error if any pragma fails

**Schema Creation Remains in Callers:**
- `internal/state/store.go:init()` — creates positions, order_attempts, risk_snapshot, strategy_state tables
- `internal/ledger/ledger.go:migrate()` — creates trades table
- Each package retains full ownership of its schema; only the generic "open a durable SQLite connection" part is shared

### Refactored Callers

**`internal/state/store.go`:**
- Removed imports: `"os"`, `"path/filepath"`, `_ "modernc.org/sqlite"`
- Added import: `"titan-algo/internal/dbutil"`
- Replaced `Open()` function's directory creation + `sql.Open()` + pragma setup (lines 56-72) with single call to `dbutil.OpenSQLite(path)`
- Removed pragma loop from `init()` method (lines 93-102), replaced with one-line comment noting pragmas are pre-configured
- Result: 15-line reduction in boilerplate, zero functional change

**`internal/ledger/ledger.go`:**
